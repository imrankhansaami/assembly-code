# CSE 436 - Computer Interfacing Lab

8086 assembly language lab work (emu8086, DOS INT 21h).

- **Q1_44008.asm** - Lab Test 2, Question 1: buffered text input (max 60 chars), case conversion (upper / toggle) using XOR 20h, character counts, and stack-only reversal.
- **Q2_44008.asm** - Lab Test 2, Question 2: masked password entry (no echo, `*` per character, max 12), login with 3 attempts, then new-password setup (match + minimum length 6 + at least one digit).
